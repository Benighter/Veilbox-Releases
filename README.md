# Veilbox

One private workspace for all your disposable email inboxes, on Windows and Android.

## Get the app

- [Windows portable app](https://github.com/Benighter/Veilbox-Releases/releases/latest/download/Veilbox-1.0.0-Portable.exe)
- [Android APK](https://github.com/Benighter/Veilbox-Releases/releases/latest/download/Veilbox-1.0.0.apk)
- [Release notes and checksums](https://github.com/Benighter/Veilbox-Releases/releases/latest)

Open the Windows app, or install the Android APK, then choose a vault password. Create an address and copy it into a website's signup form. Use the combined inbox or select one address to read messages.

## What's new in 1.0.0

- Create random or custom disposable addresses for shopping, newsletters, trials and one-time signups.
- Read real incoming mail in a combined inbox or individually.
- Copy verification codes, star messages, archive them, and move them to a local Bin.
- Mute addresses and filter senders globally or per inbox.
- Keep a private signup tracker and find unsubscribe links in mail headers.
- Lock your locally encrypted vault and export encrypted backups between Windows and Android.
- Check for Android updates from Settings. Downloaded updates are verified before Android's installation prompt.

## Before you use it

Addresses are temporary and receive-only, powered by [Mail.tm](https://mail.tm). Some websites reject disposable addresses. Creation, quotas, retention and availability depend on the provider. No personal email is required. Mail.tm stores incoming mail; vault encryption protects locally saved credentials and messages.

Signup tracking does not sign you up or unsubscribe you automatically. Muting and blocking filter the app's views; they do not stop delivery at the provider. Deleting an address permanently removes the remote mailbox and its local records.

Keep your vault password safe: there is no reset service. Use Settings to export an encrypted backup. Restoring on another device copies the vault; it does not enable automatic synchronization between devices.

This repository contains only distribution metadata, release notes, checksums and app downloads. Implementation source and signing material are not published here.
